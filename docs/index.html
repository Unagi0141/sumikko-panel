画面の端を、ちゃんと空けてくれる。

任意の Web ページを画面端に常駐させます。他のウィンドウを押しのけて設置できるので、 アクティブウィンドウを最大化しても閲覧可能です。

ダウンロード Windows 10 / 11 · 64bit v0.9.14 ベータ · 約 106 MB

できること

置いておくための道具です

一日じゅう出しっぱなしにしても邪魔にならないことを目標に作っています。 細いカラムで読めること、他の作業を妨げないこと、勝手に静かになること。

画面の領域を予約する

Windows の AppBar として登録するので、最大化したウインドウがドックの手前で止まります。 「常に最前面」で無理やり浮かせる方式とは違い、他のアプリの邪魔をしません。

全画面アプリのときは引っ込む

ゲームや動画が全画面になったことを検知して、自動的に隠れます。戻れば また出てきます。

文字だけ大きくする

ブラウザの拡大と違い、本文の文字サイズだけを上げます。余白も画像も膨らまないので、 細いカラムのまま読みやすくできます。画像は畳んでおいて、クリックで開けます。

新着を知らせる・流し込む

新しい投稿を検知すると短い音とバッジで知らせます。先頭を見ているときは、 待機中の新着を再読み込みなしで流し込みます。読んでいる最中は止まります。

好きなページを並べられる

URL を指定すれば何でも置けます。カラムは横にも縦にも並べられ、 幅はドラッグで変えられます。サービスごとにログイン状態は別々に保たれます。

設定ファイルで拡張できる

対応サービスは JSON で定義されています。1 項目足せば増やせるので、 アプリの更新を待たずに自分で対応させられます。見た目も CSS で調整できます。

警告が出ます

このアプリにはコード署名を付けていません。 署名の証明書は個人が継続的に持つには高く、無料で配るアプリには見合わないためです。 そのため初回の起動時に Windows SmartScreen の警告が出ます。隠さずに書いておきます。

  1. 「WindowsによってPCが保護されました」と出る
  2. 詳細情報 をクリック
  3. 実行 をクリック

内容が気になる場合は、ソースコードを読んでから判断してください。全部公開しています。

何も送信しません

利用状況の収集も、外部への送信も一切ありません。設定も、各サービスのログイン状態も、 すべてお使いの PC の中だけに保存されます。保存先は設定から変更できます。

各サービスへの通信は、そのサービスの Web ページを表示するためのものだけです。 アプリを削除したい場合は、アンインストール後に %APPDATA%\Sumikko Panel を削除してください。

まだベータです

いまのところ、作者の PC でしか動かしていません。画面の数や解像度が違うと、 どうなるか分かっていません。どこか壊れている前提で 触ってみてください。

「ここ変だぞ」と思ったら こちらから教えてください。 GitHub のアカウントは要りますが、それだけです。文句でも要望でも大歓迎です。

更新は自動で受け取ります。次にアプリを閉じたとき、こっそり入れ替わります。

補足

できないこと

先に知っておいたほうが、がっかりしなくて済むと思うので書いておきます。

  • 各サービスの API は使っていません。Web ページをそのまま表示しているので、 サービス側の作りが変わると、文字サイズの調整や新着の検知が効かなくなることがあります。 その場合は設定から CSS と定義を直せます。
  • ログイン情報は保存しません。各カラムの中で 1 度ログインしてください。 ログイン状態はそのまま保たれます。
  • Windows 専用です。画面領域の予約と全画面の検知が Windows の機能に依存しています。
  • 軽くはありません。カラムごとに表示エンジンを抱えるので、2 カラムで数百 MB 使います。
